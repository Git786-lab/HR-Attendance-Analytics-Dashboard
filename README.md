# HR-Attendance-Analytics-Dashboard

Project Title
HR Attendance Analytics Dashboard

Headline
Power BI dashboard for analyzing employee presence, work-from-home, and sick leave trends

Built an interactive HR analytics dashboard in Power BI to track employee presence, work-from-home behavior, and sick leave trends. Transformed multiple raw Excel sheets into a unified dataset using Power Query and automated data cleaning steps for future updates. Designed visual insights that help HR and management identify workforce patterns.

Tech Stack
Power BI
Power Query
DAX
Excel

Business Use Case
This dashboard helps HR and management make better workforce decisions. For example, if the company plans to launch a new project or schedule a release that requires most employees to be available, they can use this dashboard to identify:
• Which months have the highest presence percentage
• When sick leave trends are high (e.g., seasonal patterns)
• Whether more employees are working from home during certain periods
This allows the organization to schedule major tasks or releases at a time when maximum staffing and support are available.
